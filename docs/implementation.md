# Implementation Log — Rain Dodger

Living document that tracks the app from Xcode template to a working app, and records the **user's changes in each phase**. Each phase is executed with `@implement <Phase>` and verified with `@review`; every change made in a phase is documented here (see **Change Log**). A phase is **done** only when everything in its checklist is complete, the project builds (`xcodebuild build -project RainDodger.xcodeproj -scheme RainDodger`), and `@review` reports clean.

## How to work this file

- Each phase is executed with `@implement <Phase>` (or ran as its own plan), then checked with `@review`.
- Tick checkboxes as work completes; move a phase to `Done` only when verified.
- Feature work always follows `.opencode/rules/003-project-guideline.md`; visual work follows the feature's design doc in `docs/designs/`; scope follows `docs/template/spec-guide.md`.
- Never commit or push here — the user does it explicitly with `@push`.

## Phase 3 — Rain Forecast Layer (feat/weather-forecast)

Goal: per-point rainfall forecast along the **selected** route so riders see where the road will be rained on, color-coded on the map with a legend + wet distance.

**Scope banner:** selected-route-only forecast (unselected alternatives get no weather; re-select re-fetches, cached routes reuse segments); no dry-route ranking / departure-time sweep (moved to Phase 4); no SwiftData/persistence; no changes to the trip-planner routing shell beyond wiring weather in; WeatherKit entitlement added in repo but **live WeatherKit = device-only manual validation** (mock-verifiable path now).

- [ ] WeatherKit entitlement `com.apple.developer.weatherkit` in `RainDodger/RainDodger.entitlements`
- [ ] Protocol-first `WeatherService` (Live via WeatherKit `currentWeather` + `minuteForecast`/`hourlyForecast`; Mock with deterministic scripted probabilities)
- [ ] Selected route polyline sampled every 5 km (cap ~60 samples); per-sample arrival time = `departureDate ?? now` + proportional fraction of travel time; `rainChance` fetched in a bounded TaskGroup (chunked ≤ 8)
- [ ] Blocking "Checking rain along your route…" loading overlay over the map while weather computes
- [ ] Color-coded route segments on the map (<30% route-blue / 30–60% yellow / ≥60% red) REPLACING the selected route's blue stroke; unselected alternatives muted as today
- [ ] `RainLegend` (Dry/Light/Heavy rain chips + % ranges) + wet-distance line ("14 km of 40 km with rain ≥ 50%"); text not color-only
- [ ] Offline/WeatherKit-fail degrades to a non-blocking "live rain unavailable" banner; route fully shown, plan not failed
- [ ] `@MainActor @Observable` `TripPlannerViewModel` injects `WeatherService`; `ContentView` injects `LiveWeatherService`; all previews use `MockWeatherService`
- [ ] Accessibility per 004 (VO labels, non-color-only, ≥ 44 pt, Dynamic Type, Reduce Motion)
- [ ] Build passes (`.opencode/scripts/xcode-tools.sh build`), `@review` clean
